# Prevent Thrall

Stops accidental thrall recasts on the Arceuus spellbook.

While your thrall is out, the nine Resurrect thrall spells are greyed out and left-clicking them does nothing. You can still cast one on purpose by right-clicking the spell and choosing **Cast**.

The block starts when your thrall is summoned and lasts until the game tells you it has returned to the grave, so it follows your real thrall uptime rather than a fixed timer.

## Settings

- **Grey out blocked spells**: dim the thrall spells while blocked (on by default).
- **Dim amount**: how faded the blocked spells look.
- **Block left-click**: ignore left-clicks on the thrall spells while blocked (on by default).
- **Thrall expiry message** (Advanced): the game message text that ends the block. Only change this if Jagex changes the wording.
